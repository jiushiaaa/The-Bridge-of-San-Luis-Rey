# 圣路易斯雷大桥

根据 Thornton Wilder 1927 年同名小说改编的完整互动文学游戏。本体版本 **1.0.0**，三卷 36 张残页、序幕与六节尾声均可从头游玩至读后页。

![游戏封面](docs/screenshots/cover.jpg)

一座桥倒塌，五个人死去。一名修士试图从他们的生平中寻找原因。玩家沿人物名字寻找散落的生活，辨认关系，将事件归回有依据的阶段，最后读到留下来的人如何继续生活。

## 开始阅读

需要 Node.js 22 或更高版本、npm、Python 3。在仓库根目录运行：

```sh
npm --prefix game ci
npm run build
npm run preview
```

浏览器打开 **http://127.0.0.1:4186/**。保持服务窗口打开；退出用 Ctrl+C。已构建的 macOS 本地工程也可双击 `开始阅读.command`，然后打开该地址。不要直接双击 `dist/index.html`：模块加载与书签保存需要 HTTP 服务。

开发用 `npm run dev`，地址为 `http://127.0.0.1:5186/`。生产包输出到 `dist/`，资源使用相对路径，可由普通静态服务器托管。运行游戏不需要 API key 或在线模型调用。

## 完整本体内容

| 卷次 | 人物与内容 | 核心阅读问题 |
|---|---|---|
| 第一卷 · 信 | 侯爵夫人、佩皮塔、克拉拉与院长 | 爱能否不再索取回应？ |
| 第二卷 · 名字 | 曼努埃尔、埃斯特班与船长 | 一次帮助能否因后来的灾难而失去意义？ |
| 第三卷 · 台下 | 皮奥、卡米拉、海梅 | 照料与控制怎样出现在同一段关系里？ |
| 尾声 · 留下的人 | 修士的研究、葬礼、两次来访、院长的日常 | 没有得到解释，人怎样继续照顾彼此？ |

- 36 张必读残页，12 项人物档案，9 道卷末事实回顾，3 处可选页边记。
- 正文与序尾共 **19,624 个非空白字符**，其中主线残页为 16,342 字符。没有等待、体力或反复刷取机制。
- 暖纸、铜版线描与水彩画面；7 张场景、10 个不同人物头像形象，双生子共享形象，总督用姓名印记。
- 5 首背景曲已接入封面、三卷与尾声；2 段环境音作为备用素材随包保留。
- 桌面和手机阅读布局；17–25 px 字号；可关闭音乐；提示不扣分，错误判断可改正。
- 完成后可重读全部残页及尾声，保留个人页边记。

## 书签

独立运行使用当前浏览器、当前网址的 IndexedDB。设置中可下载或导入 JSON 书签；换端口、换浏览器和清理网站数据不会自动迁移进度。重新开始前可以下载当前书签。

在注入 `window.LumiMakerSdk` 的幻光播放页中使用平台云存档。读取失败时暂停写入，不把失败当成空档，也不会暗中切换到本机存档覆盖云端进度。真实平台发布与跨设备云存档尚未验收；仓库上传不等于幻光发布。
