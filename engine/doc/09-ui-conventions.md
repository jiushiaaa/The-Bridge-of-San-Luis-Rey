难度与星级](03-gameplay-logic.md#难度与星级-setdifficulty--starbreakdown)。体力见底时，「体力不足」浮窗出现在体力数字下方，内含「休整(+N)」按钮。
- **全局字体**：UI 用 Inter + Noto Sans SC（构建期自托管 OFL，仅 400/700，禁止 500/600 假粗）。章节/旁白/回顾等长文用 Noto Serif SC。离线版把 woff2 拷到 html 同目录；缺文件时回退系统黑体/Georgia。日语 / 繁体走系统字体栈（`html[lang=ja|zh-TW]`），不内联全字库。西语排版差异见 [13 §6](13-i18n.md)。
- **纸刊定稿**（原 style-lab v6 已合并进 `styles.css` + `theme-editorial.css`）：冷纸底 `#e8edf3`、海军强调 `#3d4f6f`（`--leather` / `--gold` 都指向它）。词条卡顶沿正中短横条（`.entry-pin`）；地点卡横条收在卡内并 `overflow:hidden`，底图 18s 轻缩放。标题页 / 情节 CG / 地点底图 / 时间轴格子图 / 回顾主图同样慢呼吸。情节卡左列当前项冷纸底 + 加深纸影，页不位移。进页只淡入、不位移；切页签海军色块滑动，内容淡入。按钮等 hover 上移 1px，按下 0.97。`prefers-reduced-motion` 时关掉。后续视觉试验走 `style-lab.html`，游戏页不再挂风格切换条。
- **图标**：形态图标为 SVG 组件 `FormIcon`（星=情节/双气泡=对话/单气泡=独白，currentColor）；favicon **按作品分**——各作 `assets.favicon`（主题图标裁切版，`tools/gen_scene_icons.py` 生成，main.tsx 运行时设置），缺失时回退程序绘制的 `frontend/public/favicon.ico`（vite publicDir，`gen_icons.mjs` 生成）；TAB 与词条分类用 emoji（故事页签为文字「故事」；📜🕰️🗂️📖 / 👤📍⚔️💡）；未知 NPC 为程序绘制的透明底剪影 `assets/images/npc_unknown.png`（`tools/gen_icons.mjs` 可重生成）。
- **背景音乐**（`game/bgm.ts`，仅作品 `assets.bgm` 非空时启用）：页签栏右端、体力左侧挂**迷你播放器** `BgmMiniPlayer`（`.bgm-mini`）：左＝**黑胶封面按钮** `.bgm-mini-disc`（`BgmDisc`：圆形封面 + 中心孔；播放中 6s/圈旋转、底边一枚 9px 音符左右轻晃 `.bgm-mini-swing`、悬停浮出暂停；停止时封面压暗常显播放键；点按即播放/暂停）；中＝曲名 + 细进度条（曲名 12px 常规字重、`--ink-80` 深灰、**固定 6em 宽**，放不下时 `Marquee` 缓慢走马灯 16px/s，文字接一份副本、间隔取容器宽 1/3（留空不超过一半）、两端 6px 渐隐；进度条 2px 只订阅 `useBgmProgress()`，不带整块重渲染）；右＝齿轮（右下角叠 9px 小图标表示当前模式）。齿轮 / 曲名点开 `.bgm-pop`（点外面 / Esc 收起），内容为共用的 `BgmMenu`。
  - **歌单按关**（[14 §5](14-bgm-pipeline.md)）：歌单 = **本关已解锁曲** + 玩家临时勾进的往期曲（`pinned`）− 取消勾选的本关曲（`excluded`）；进关（从封面进入 / 过关 / DEBUG 跳关）即清空这两项、只剩本关开篇曲并起播。`localStorage baima:bgm:<game>` 只存播放模式。菜单列表分三组小标题 `.bgm-track-group`：**本卷曲目 / 往期曲目 / 未解锁**；每行「封面 | 曲名 / 来源 | 复选框」，来源 = `第 N 卷 · 情节卡名`（开篇曲写「开场」，封面曲「封面曲」，结局「结局」；未补完的卡名显示「？？？」，未解锁行灰显带锁、封面不露图防剧透）。正在播的那行封面旋转。歌单至少保留一首（最后一首的复选框禁用）；取消正在播的那首立刻切下一首；点某行 = 切播它（不在歌单则顺手勾上），点当前行 = 暂停/继续。
  - **封面**取「获得它那一刻的画面」（`bgmCover`）：`unlockCard` 曲 → 该情节卡 CG；到卷解锁的曲 → 该卷开场图；封面曲 / 结局曲 → 标题图 / 结局图；圆形裁切即取图像正中区域。
  - **三种模式**：**随机播放（默认）**＝为整份歌单生成一份随机序列顺着播、一轮播完重新随机（新一轮首曲尽量不与刚播完的相同；歌单变动 / 手动点播 / 新曲入单时以当前曲为首重排）；循环播放＝按表中顺序逐首；单曲循环＝`audio.loop`。封面页固定播封面曲；进关从本关开篇曲起播；结局页播结局曲。
  - **本关新解锁的卡曲立刻入单并切过去播**（玩家手动暂停时只换当前曲不强行起播）；回补往期卡解锁的曲只 toast。**新曲光效**（`.bgm-mini.is-new`，约 8s，`bgm.newTrackId`；进关拿到开篇曲同样触发）：暖金 `--bgm-glow #d8a743`（刻意跳出蓝灰主题）——唱片金色辉光 + 1.12 倍呼吸 + 两圈从唱片向外扩散渐隐的「声波光环」（`::before/::after`，错相 0.8s）；整块播放器边框转金、`box-shadow` 呼吸、一道斜向高光反复扫过（`::after` + `mix-blend-mode: screen`）；曲名转金加粗带光晕、进度条转金、「新曲」角标弹出改金。点开菜单 / 点播 / 播放暂停即停；`prefers-reduced-motion` 退化为静态金边；手机版只保留唱片部分（`theme-portrait.css`）。toast 仍照旧报「解锁新曲」。
  - 「菜单」弹层里的 BGM 行（`BgmPlayer`）复用同一份 `BgmMenu`——封面页没有页签栏、竖版顶栏只放得下黑胶按钮（点按 = 播放/暂停），歌单与模式都从那里进。
- **Toast 同屏上限 2 条**（`store.ts` 的 `TOAST_MAX`，底部居中竖向堆叠，每条 2.6s 自动消失）：超出时最旧的立即被顶掉——整行/整列归位、连片归位、首次收集词条等会一次连报多条，不设上限会糊住底部界面。
- 「名场面」仅为数据键名（cols[0]/form），界面一律显示「情节」。

## 2. 窄屏自适应（三级断点）

断点在 `frontend/src/game/layout.ts`（`BP_MID=1280` / `BP_NARROW=1100` / `BP_PHONE=768`，`useLayout()` 基于 matchMedia）与 `styles.css` / `theme-portrait.css` 的 `@media` **各存一份，改动必须同步**。

- ≥1280 全展开；
- <1280 时间轴右栏「关卡出口」默认折叠成 34px 竖条 `.tl-gate-tab`（可答题时竖条上带 `.gate-cta-reddot` 闪烁红点），展开为浮层 `.tl-right.floating` 覆在表格上、**不二次挤压中区**（宽屏展开态也可用「收起 ▸」手动折叠）；
- <1100 且当前为「情节卡」页时再收起右区，页签栏右端出现虚线框入口 `.tab-entry`（带同一份搜寻角标 `useSearchCount()`），点开为贴右缘的抽屉 `.pane-right-drawer` + `.drawer-mask`（点遮罩 /「关闭 ✕」/ Esc 关闭，`ui.entryDrawer`）；时间轴/档案页不显示该入口；
- `.app` 的 `min-width` 为 960，更窄才回退横向滚动。

### 2b. 竖版（phone）

`layout.ts` 增加 `phone`：`max-width < 768`，或 `orientation: portrait` 且 `max-width < 960`。`html[data-layout="phone"]` 钩住 [`theme-portrait.css`](../frontend/src/theme-portrait.css)。桌面横屏（≥960）行为不变。

竖版壳层：顶栏 HUD（刊名 / 返回 + 体力 + 提示菜单）+ 底栏四页签；情节卡与档案为主从全屏（`ui.mobilePane`）；词条库与关卡出口为底部抽屉。横持且 `max-height < 500` 时提示竖持。

- **主从返回按钮写清目的地**：情节卡为「‹ 卡片列表」、档案为「‹ 档案列表」（`phone.backCards` / `phone.backArchive`）。全屏详情里只写「返回」看不出退到哪一层。
- **关卡过场**：竖屏改「上画带 + 下常规流」。`--intro-art: min(48dvh, 62vw)`（带高贴近 16:9，`cover` 几乎不裁），带外由同一张图放大模糊的 `.lv-intro-haze` 铺底兜住，底缘用 `mask-image` 渐隐。正文回到常规流、`overflow-y:auto` 且可收缩，进度点与「继续」按钮（整宽 48px）钉在安全区之上。横版那套「文字浮在 58% 处」到竖屏会两头落空：`cover` 裁掉大半张画，长段正文又顶穿屏幕。`.lv-intro` 必须写 `-webkit-tap-highlight-color: transparent`——整屏是点击推进层，默认高亮看着就是「每点一下全屏闪一下」。
- **时间轴**：竖屏改「上表下手牌」。`.tl-board-wrap` 自成滚动容器双向滚动，`thead th` 吸顶、`th.row-head` 吸左（外扩 12px 同色阴影糊掉 `border-spacing` 的缝，层级要压过格内 chip/对勾/箭头的 `z-index:3`）；`.tl-left` 用 `order` 调到底部成一条横滑手牌区（拇指够得到，原先压在顶上既吃掉三分之一屏又离落点最远）；落位提示 `.tl-hint` 钉在表格下方不随表格滚走。归位一律点选（禁用 HTML5 拖放）。

**所有侧栏一律 `flex: 0 1 <基准宽>` + `min-width` 下限**（`.pane-right` 320/248、`.tl-left` 252/168、`.tl-right` 250/190、`.card-list` 300/208、`.arc-list` 300/208、`.arc-hero-col` 300/200），压缩由各列按基准宽等比分担——历史问题：侧栏曾是 `flex: 0 0` 不可收缩，窄屏时全部压力落在中区，时间轴格子被压到不可读。竖版下这些并列栏改为堆叠 / 抽屉，不再走等比压缩。

## 3. 情节卡

- **顶栏 `.chat-head`**：形态字标 + 标题（未补完=？？？）+ 右侧状态区。右侧按状态给三种东西：未补完/已归位显示状态章 `.status-seal`（可填写 / 待补全 / 已归位，两态判定同列表，**样式也与列表状态章完全一致**：宋体、无底色，待补全灰、可填写海军加粗带扫光下划线——`theme-editorial.css` 里 `.card-item .status-seal` 与 `.chat-head .status-seal` 写在同一条规则）；**已补完未归位显示朱红「待排序」按钮**（`.status-sort`，同 `gotoTimeline`，与列表状态章功能一致：跳时间轴页签并选中该卡）；有 CG 的补完卡再跟一个「🏞️ 图像」重放按钮（`.cg-replay-btn`）。两者并存时顺序为 `[待排序][图像]`，靠 `margin-left:auto` 整体右对齐（后一个不再吃 auto 边距）。
- **聊天气泡一律居左**（头像在左、气泡在右）；独白只换底色（金底 / 纸刊定稿为海军淡底），**不用斜体**，同样居左。配角气泡（`speaker` 文本名）不配头像，渲染淡色首字印章（`.seal.soft`），不抢视线。
- **正文排版对齐一条竖线**：发言人列 `.speaker-col` 固定宽 `--speaker-col-w` 64px（= `speaker-name` 的 `max-width`），与气泡间距 `--speaker-gap` 8px，二者之和 `--speaker-area`（72px，定义在 `.chat-body`）即「对话时头像区占用的宽度」。旁白 `.msg-narr` 左右各留 `--speaker-area` 的外边距，对话行 `.msg-row` 右侧留同一宽度的内边距，于是旁白与气泡的左右边缘都落在同一列上。旁白 15px / 1.8（宋体，首行缩进 2em）；**所有气泡 `.bubble`（对话 / 独白 / 故事页引语）统一黑体 `var(--font)` 15px / 1.8、`font-style: normal`**。故事页引语 `.recap-quote` 同规则：右侧留 40px 头像 + 10px 间距的空白。
- **填空 UI**：`BlankButton`（`.blank-btn`）**左侧带齐边（上/下/左）正方形图标**（`.blank-btn-icon` 1.9em 见方，`Avatar fill`；`.blank-btn-text` 高度钉死同为 1.9em——否则按钮被文字行高撑高，头像格贴不到底边露 1px 底色）——已选→所选人物头像/地点图；未选→默认 NPC 头像（`data.assets.mysteryAvatar`）或图针 📍（`.blank-btn-pin`）；右侧文字：人名空未选显示 slot 名（NPC1/NPC2…）而非「选择人名」、地名空未选显示「选择地名」，已选显示词条名，已锁定显示「slot＝名 ✓」。正文中 `[[NPCn]]` 占位（`RichText`，`.npc-unknown / .npc-draft / .npc-known` + 内层 `.npc-ico` / `.npc-label`）**与底部 `BlankButton` 同一套外观**：行内高 1.7em 的小方框，左侧齐边正方形图标（`Avatar fill`，不用圆头像），右侧文字；未填 = 按槽位染色的虚线框 + 剪影 + slot 名，草稿 = 实线框黑字 + 所选头像 + 人名，锁定 = 金框金底金字。验证失败草稿清空回退虚框占位；气泡发言人栏同规则。**`.npc-ico` / `.npc-label` / 旁白里的 `.entry-chip` 必须写 `text-indent: 0`**——旁白的首行缩进 2em 会被这些行内 flex 容器继承成一段首行空白（曾表现为图标与「NPC1」之间莫名空出两个字）。
- **底边栏右侧两个按钮**：「⚡提示」（`.blank-hint`，闪电图标金色；按钮上不写体力消耗，悬浮 `title` 里才说明规则与花费）+ 主色「验证此卡」。提示逻辑见 [03 · ⚡提示](03-gameplay-logic.md#情节卡提示-hintcard)，界面反馈两种：被替玩家填对的空位金色闪三下（`.blank-btn.hint-flash`，1.5s）；答案未收集的空位朱红虚框亮出答案并左右轻震（`.blank-btn.hint-peek`，3s，不可点），期间提示按钮改写为朱红「尚未收集」、「验证此卡」禁用。卡内**没有提示文案区**（`hints` 字段已废弃）。
- 词条 chip 的「✓」仅表示**本卡内**已点击收集（`famCards` 含本卡）；人物 chip 熟悉度 ≥1 时带头像，此时整个 chip 切到与人名空位 / 底部填空按钮同款的方框结构（`.entry-chip.has-ico`：1.7em 高、左侧 1.7em 见方齐边头像 `.chip-ico` + 右侧文字 `.chip-text`），不再是小圆头像贴在文字前。本卡首次点击时 chip 从左向右刷一层本色（`.collect-fx`，约 0.5s），对勾随后弹出；已点过的 chip 不再播。
- **填卡候选抽屉 `.blank-sheet`**（点填空按钮在底边栏上方展开，不是居中弹窗）：人物 72px 小方卡、地点 140px 小图卡，`flex-wrap: wrap`——候选少时一行，多时自动折成多行在抽屉内竖滚（`.blank-sheet-body` 默认最高 min(28vh, 240px)，人物 > 8 / 地点 > 5 时加 `.is-many` 放宽到 min(44vh, 400px)）。**`.chat-wrap` 与 `.blank-sheet-body` 必须 `min-width: 0`**：这里曾是单行 nowrap + 横滚，收集到 25 个地点时这一行的 min-content 把没有 `min-width:0` 的 `.chat-wrap` 撑到 3700px，整个情节卡列被顶出屏幕、列表被压扁；人物抽屉同样会撑到 2000px+。
- 填卡候选中地名与词条库一致显示词条简介，人名仍显示熟悉度文本；「补全档案空缺」弹窗则每个候选显示**词条简介 + 圆点熟悉度**（PickerItem.fam 标记，复用词条库 FamDots 样式）。
- **已归位卡的底部跳转条 `.chat-nav`**（正文流末尾）：**居中一行 CG 缩略图**，`width:fit-content` + `justify-content: safe center`，装不下横向滚动（`safe` 保证不切掉第一项；项数多时会退化成左对齐，这是不裁切的代价）。每项 `.chat-nav-item` 是 **128×72**（近 16:9）的圆角块：`.chat-nav-cg` 真实 `<img>` 铺底（**禁用 CSS `url()`**，同 [11](11-cross-mode-pitfalls.md)），`::after` 压一层上深—中浅—下深的渐变，左上角 `.chat-nav-tag` 小角标写关系，底部 `.chat-nav-text` 白色粗体标题。**配色刻意与旁白、气泡拉开**：深底白字 + 投影，一眼看出这不是故事文本而是导航。
  - 角标内容：时间方向项写「上一节 / 下一节」；同时段项写**该卡所属的列**，并在名字前带一枚 14px 小头像（人物列用其头像、情节列用作品主题图标、未收集的人物用剪影 +「？？？」）。
  - 方向指示 `.chat-nav-edge`：`‹` / `›` 贴在上一节的左边缘、下一节的右边缘，靠一条 `linear-gradient` 融进底图，不额外占一格；角标与标题各自让出 26px 免得压在箭头上。hover 时箭头转金。
  - 分组：**时间方向（上/下一节）与同时段横切面之间插一条金色 `.chat-nav-sep` 分割线 + 加宽留白**。金色是为了在两侧都读得见——一边可能是深色 CG，另一边可能是纸色虚框。
  - 目标卡未补完时整项 `.veiled`：**不渲染 `<img>`**（与格子 CG 同一套防剧透规则），换成不透明纸色底 + 45° 细斜纹 + 皮革色虚线框，标题显示「？？？」。这里必须写 `opacity: 1` 盖掉全局 `button:disabled{opacity:.45}`——半透明会让当前卡的背景 CG 从底下透上来，糊成一团还容易被误读成目标卡的图。
  - 完整的「方向 · 所属列 · 标题」放在 `title` 悬浮提示里。

## 5. 时间轴信息密度（`Timeline.tsx`）

表格近乎铺满中列宽（`table-layout:fixed`，宽 `calc(100%-32px)`，格高 96px；行头列 60px 按文字实际需要收窄（上限 84px），右侧 32px 空档缓和行头列造成的偏右、优先保格子面积；中列滚动条以负外边距贴紧右侧分割线，同 `.tl-right` 手法），chip 铺满整格。

chip 显示句首摘录（未补完）或标题（已补完），标题两行自动换行，不显示人物头像与形态图标——未补完=灰底深灰字、已补完未锁定=形态主题色边框+文字（情节=朱红/对话=青绿/独白=褐）、锁定=金色描边；**补完卡以其 16:9 CG 铺满格子作底色**（`.tl-chip-cg` 真实 `<img>`，标题压深色渐变白字；未补完不显示防剧透）。

**点选任意格中卡（含已锁定）→ 整格换成信息面板**（`.tl-chip.expanded .chip-info`，纸色底 0.93 盖住 CG 保可读，格约 100×88px）：**不显示标题**；首行为 18px 人名头像（`SlotRow` 的 `personOnly`，不出地名胶囊以省宽度）+ 右端「阅读」（`.tl-pool-read` 展开态回到常规流），头像区 `flex:1` 只吃按钮之外的宽度、放不下的部分靠 `mask-image` 向右渐隐而非被按钮压住；下方 10px 预览正文填满剩余高度，**形态字标内嵌在正文开头**（`.chip-info-preview .form-tag`）。

未选中态不变（未补完=摘录 / 已补完=标题 / 已锁定=绿勾+标题）；chip 点击不再冒泡到格子（放置需点格子空白处），锁定卡被选中时不出现放置提示、格子不高亮；**情节列头显示作品主题图标**（52px，`assets.sceneIcon`）；**行头时间点名默认隐藏**（「时间 N」+「提示♥」按钮花 1 体力揭示 `revealRowName`，整行归位自动揭示）；行头/列头不显示完成度数字，整行/整列归位后变金；选中残页时底部改显示低调提示「放入上面格子」（复用 `.tl-hint` 样式）；行/列/连片新锁定时 `pulseFx('gateprog')` → 关卡出口进度条与归位计数闪光（`GatePanel` 的 `.flash`）。

**右栏顶部是关卡带 `.lv-bar`**（`LevelBar.tsx`，在「关卡出口」面板之上）：`.lv-chip` 每格两行居中——「第 N 关」+ 10px 小字「N 段情节」。**不显示关名与星级**（关名剧透走向，段数只透露长度）；已通关可点、当前关关号朱红、未开启的虚线灰显不可点。

**恒为一行、一页 3 关**：`flex-wrap: nowrap` + `overflow: hidden`，既不换行也不出滚动条。超过 3 关时两端出 `.lv-page`（`‹` / `›`）翻页；当前关（或正在回顾的关）换页时会自动翻到它所在那一页。

- 每格**固定 62px**（`.lv-chip` 的 `flex: 0 0 62px`），**不随本页格数拉伸**：末页只剩 1~2 关时是 `.lv-bar-track` 的 `justify-content: center` 把它们居中，而不是把格子拉长——同一个关卡在哪一页看都一样大。
- 尺寸三个常量在 `LevelBar.tsx`（`CHIP_W=62` / `ARROW=14` / `GAP=3`）与 CSS 里各有一份，**必须同步**。227px 宽的右栏实测：3 格 + 两个箭头刚好放得下且文字不截断。
- 只有窄到连 3 格都摆不下时才按 `ResizeObserver` 实测宽度降级到 2 或 1 格，不会溢出。

进入只读回顾后，左列隐去（不再放成绩单），格子不可放置，行头时间名全部揭示，闸门面板换成 `.tl-right-review`：一句说明 + **`[data-exit-review]` 一键返回按钮**。这个按钮不能省——关卡带会分页，当前关未必在这一页上，只靠点关卡带回去可能要先翻页。

**表格下方**：`.tl-hint` 提示行 → 解锁后的「📖 回顾本关故事」金框大按钮 `.tl-recap-btn` → `.tl-foot-tools`（并排两个 DEBUG 入口：时间轴 / 故事回顾）。

**关卡出口面板（`GatePanel.tsx`）**：右栏 `.tl-right` 与情节卡页的词条库 `.pane-right` **同宽**（`flex: 0 1 320px; min-width: 248px`），两个页签之间右栏不跳宽。面板没有「关卡出口」字样行；头部第一行是卷名 `[data-gate-chapter]`（`levelChapterTitle`，与「故事」页同源同字），下面那句是本卷之问（`[data-gate-question]`，无 `question` 回退 `intro`）。`.gate-cta` 大按钮是「展开问题 / 收起问题」，**任何进度都可点**（≥70% 且未展开时带红点），题目默认折叠；展开后 `revealAt:"start"` 的题面直接显示，其余在 70% 前显示「？？？」（`.gate-q.is-hidden`，字距拉开、灰字）；**70% 前不渲染答案栏**（`.gate-sheet.is-locked` 下只有题面：不能填、不能提交、没有「核对答案 / 自动填写」脚部），也**没有任何**「这题可以答了」之类的点亮提示——答案栏出现本身就是信号；`data-gate-expand` 属性保留给测试。

**左列「待归位情节卡」与格内未补完卡**：左列标题只有「待归位情节卡（N）」，不再有「残页」小字；未补完的卡在左列用 `VeiledTitle` 模糊标题（`.tl-pool-text.is-veiled`，与情节卡列表同款），下方是正文摘录。未补完的卡放进格子后，`.tl-chip.undone` 改为 `justify-content: flex-start`：顶部一行模糊标题（`.tl-chip .title-veiled` 用更深的墨色、收紧晕影半径、去掉呼吸动画——12px 小字上原来那套近纸色大半径晕影会隐没不见）+ `.chip-preview` 预览正文（10px，最多 4 行）铺满剩余高度，不再是底部一行摘录、上方大片空白。

## 6. 词条库

**显示模式**（右栏标题右端两枚图标 `.pane-view-switch`，`ui.entryView`，偏好存 `localStorage baima:entryView`、跨作品共用）：**完整**（默认，现状）/ **精简**（`.entry-panel.view-compact`：不渲染简介 `.entry-desc`，人物头像 44→32px，地点卡不再撑 4:3 占位、底图只当一条色底，名字与熟悉度圆点同一行）。要再加模式，扩 `ENTRY_VIEWS` 与 `game.view.*` 文案即可，卡片本体不动。

人物/地点/物品为双列卡（人物带圆头像，其余无图），概念为无图标行；组内按**本关最大熟悉度从高到低**排序。**de / en 改为单列**，姓名允许换行；地点卡背景占位高度封顶 110px（见 [13 §6](13-i18n.md)）。

**分类标题后带计数 `( n / max )`**（`.entry-group-count`）：`n` = 该分类已收集数（跨关累计），`max` = 本关可收集（`collectibleEntriesOfLevel` = `levelStartEntries` ∪ 本关卡面正文 `{{词条}}`）∪ 此前已收集——旧关拿到的即使本关不出场也计入，且漏收的旧词条不抬高上限，保证收满本关即 `n === max`；**总数默认藏为 `?` 防剧透**，旁边 `提示♥`（复用时间轴 `.row-hint-btn`）花 1 体力揭示，入档 `typeHints[level]`；`n === max` 时自动显示真值并撤掉提示按钮。

**搜寻耗尽的词条隐藏搜寻按钮**（空间还给简介）；**所有搜寻按钮左侧带放大镜图标**；优先级最高者（`bestSearchTarget`，见 [03 · 搜寻](03-gameplay-logic.md#搜寻-searchentry)）放大镜朱红并带放射环 + 小幅环绕；分析入口只保留在档案界面。地点卡背景图的布局定案见 [03 · 词条库地点背景图](03-gameplay-logic.md#词条库地点背景图-entrypanel)。

## 7. 候选选择器（SlotPicker）

填卡/档案/闸门共用，为**居中弹窗**：整组皆人物 → 三列竖排大卡（900px 视口一屏 ≥3×4），其余 → 单列竖排；按组自动判定。候选排序与词条库一致：按最大熟悉度从高到低（无词条的候选如情节标题排最后）。

## 8. 档案页（`Archive.tsx`）

左列 `.arc-list` 按人物 / 地点 / 物品 / 概念分组（三态徽标：可分析 / 可填写 / 已分析），右侧 `.arc-detail` 按词条类型走三种版式：

- **人物**：卷宗 `.arc-dossier`（左 240px 立绘卡 + 右档案页两栏，带「人物档案 · 名字」标签页）。竖版（`html[data-layout=phone]`）改上下排：立绘居中封顶 240px，档案页通栏在下（`theme-portrait.css`），否则 390px 屏宽下档案页会被挤成一条窄缝。
- **地点**：全幅地点图作背景，底部浮起 `.arc-place-panel` 面板。
- **物品 / 概念**（`.arc-detail.is-item / .is-concept`，版式 `.arc-flat`）：**左、中大面积写正文，右侧一张大图**——grid 两列 `minmax(0,1fr) clamp(240px, 34%, 400px)`：左列 `.arc-flat-main` 上下排档头文字 `.arc-flat-head`（名称 / 类型 / 简介，底部细线）与各档案页 `.arc-main`（通栏、不限 720px）；右列 `.arc-flat-art` 是 1:1 大图 `.arc-hero-frame`（无图退首字印章），随滚动 `position: sticky` 吸顶；这两类不再叠右侧水印 `.arc-wash`（与大图打架）。≤1100px 时退化为单列、图缩到 260px 放到最上。不沿用人物的卷宗两栏，是因为这两类每页字段少，两栏会左重右轻、右边大片空白。

**字段行对齐**：`.arc-field` 是 `display: contents` 的两列 grid 行，`.arc-label` 与 `.arc-text` 都按 `--arc-row-h`（16px × 1.85 = 29.6px）**同一行高、行内垂直居中**（标签 14px 但 `line-height` 取整行高；正文 flex 居中），填空按钮 `.arc-text .blank-btn` 上下内距收到 2px 使总高不超过一行，因此无论正文是文字还是按钮，标签都与之对齐。

**核对行 `.arc-check-row`**：右对齐两枚按钮「⚡提示」（`.blank-hint`）+ 主色「核对」。提示逻辑 `logic.hintArchivePage` 与情节卡完全同一套（−1 体力；已收集的答案直接替填并闪烁 `.hint-flash`；未收集的亮出答案震 3s `.hint-peek`，困难难度地名只震不亮；期间按钮改写「尚未收集」、「核对」禁用；换词条 / 离开档案页 / 窗口失焦即还原），作用域键为 `arcHintKey(entryId, pageIdx)`（`ui.hintPeek / hintFlash` 与情节卡共用同一对字段）。
