# 13 · 多语言（i18n）

> 上级索引：[README_dev.md](../README_dev.md)　·　叙事翻译规范：[workspace/xidaduo/i18n/STYLE.md](../workspace/xidaduo/i18n/STYLE.md)　·　专名对照：[glossary.json](../workspace/xidaduo/i18n/glossary.json)

玩家看到的字分两层：**引擎 UI**（约 300 条，五语齐全）和 **叙事 JSON**（目前只有悉达多 `xdd` 有完整平行包）。玩法只认稳定 id；存档键仍是 `xdd_save_v1`，切语言不换档、不重开。DEBUG 编辑器 / copyedit / style-lab **不翻**，始终中文。

## 1. 范围

| 层 | 语言 | 存放 |
| --- | --- | --- |
| 引擎 UI | zh-CN / de / en / es / fr / ja / ko / hi / zh-TW | `frontend/src/i18n/ui/{locale}.json` |
| 悉达多叙事 | 同上九语 | 简体真源 `workspace/xidaduo/final_game.json`；其它语 `workspace/xidaduo/i18n/{locale}/final_game.json` |
| 其它作品叙事 | 仅简体 | 各作自己的 `final_game.json`。UI 仍可切语言，正文回退简体 |

切语言后：UI 立刻换表；当前作品若有对应叙事包则 `replaceGameData` 热替换整份 JSON（词条名、卡标题、正文、`{{eid\|显示名}}`、时间轴列名、BGM `title`、过场/回顾/闸门文案一并换）。没有包就继续用简体叙事。

## 2. 语言与文风（悉达多）

简体中文是**唯一可写真源**。原作是赫尔曼·黑塞 1922 德语《Siddhartha》。

| 语 | 专名 | 正文 |
| --- | --- | --- |
| de | 锁定原著用字：Gotama、Sansara、Nirwana、Savathi、Samana、Kamaswami | 译游戏中文，不整段抄小说 |
| en | 与德语对齐；轮回用读者更熟的 **Samsara**（仅英语；西/法语同） | 同上 |
| es | Gotama、Samsara、Nirvana、Savathi、Samana、Kamaswami | 文学西班牙语，译游戏中文 |
| fr | 同上；Nirvâna 可带音调 | 文学法语，译游戏中文 |
| ja | 跟 glossary | 叙述常体（だ／である），不用です／ます |
| ko | 싯다르타、고타마、윤회、열반 | 한다체/해라체，不用합니다 |
| hi | सिद्धार्थ、गौतम、संसार、निर्वाण、श्रावस्ती、श्रमण | 略偏文言的现代印地语，不贴梵典 |
| zh-TW | 跟 glossary；台湾用词（祇園、沙門、輪迴） | OpenCC 初稿后再润色 |

**不译**（各语包必须与简体同值）：id、`type`/`kind`/`slot`、路径、`look`、`*Prompt`、`meta.art`、数值、`blanks.answer`（答案是词条 id）。

`{{e_xidaduo|悉达多}}` 的显示名必须等于该语 `entries.e_xidaduo.name`。时间轴情节列数据键仍是简体「名场面」；界面显示走 glossary 的 `plotCol`（de Handlung / en Plot）。列名按**简体源下标**对齐，不要按译文字面去对（OpenCC 异体字会对不上）。

## 3. 引擎

自研，不引入 i18next。

| 文件 | 职责 |
| --- | --- |
| `frontend/src/i18n/locale.ts` | 检测 / 切换 / 持久化；`html[lang]` + `data-locale`；`isLatinLocale()` = de \| en |
| `frontend/src/i18n/t.ts` | `t('toast.entryIn', { name })` 点号键 + `{var}` 插值；缺键回退简体，再缺回退 key |
| `frontend/src/i18n/index.ts` | 对外出口 |
| `frontend/src/game/data.ts` | `REGISTRY` 作品 → `LocalePack`；`pickRaw` 缺包回退 zh-CN |

**语言优先级**：URL `?lang=` → `localStorage.xdd_locale` → `navigator.languages`（`zh-TW/Hant/HK/MO` → 繁体，其它 `zh*` → 简体）→ 缺省 zh-CN。菜单语言胶囊调用 `setLocale`，立刻写 storage、改 `html lang`、通知订阅者。

**`entryName2id`**：随当前语言包的 `entries[].name` 重建。时间轴人物列、chip 显示名都走当前包，所以叙事必须整包平行，不能只翻 UI。

卷名短标签 `isChapterTitle`：汉字/假名/韩文占比 ≥40% 时上限 16 字，否则 48。过场打字机：汉字/韩文 15ms/字，拉丁文与印地语 5ms（约三倍）。`isLatinLocale()` = de|en|es|fr；印地语排版走 `isWideLocale()`（与拉丁文同：词条单列、标题下行），但不加宽字距。

## 4. 编辑器与构建

- **DEBUG 内容编辑只开简体**：`copyeditAvailable = 后端在线 && locale === 'zh-CN'`。`GET /api/data` 拉到的磁盘 JSON 存进 `zhSource`；非简体游玩时**不**用它覆盖当前语言包，避免把译文写回真源。保存始终 POST 简体 `zhSource`。
- **Vite watch**：只忽略 `**/workspace/*/final_game.json`（编辑器保存不整页刷新）。**不要**写成 `**/final_game.json`，否则 `i18n/{de,en,es,fr,ja,ko,hi,zh-TW}/` 语言包改了不会热更新。
- **离线包**：`VITE_ONLY_GAME=xdd` 时摇树只留悉达多，但其九语叙事 JSON **全部内联**（file:// 不能再 fetch）。其它作品单作包只有简体叙事。导完单作仍会全量重建 dist，见 [11](11-cross-mode-pitfalls.md)。
- **字数红线**只跑简体真源：`python tools/validate_data.py xdd`。语言包用 `python tools/i18n_check.py [de|en|es|fr|ja|ko|hi|zh-TW|all]`，不套汉字 `cardSpec`。

## 5. 叙事管线（悉达多）

**日常改简体后用增量同步**（只译改动，其余复用旧译文）：

```bat
python tools/i18n_sync.py export all [--base GITREF] [--chunks N]  :: 基线=上次同步时的简体提交（缺省 HEAD）
::   → i18n/{loc}/_sync_base.json（骨架：非文本字段全跟随简体）+ _sync_todo_{k}.json（[{path, zh, ref, ref_zh, ctx}]）
::   卡片段落按 (speaker, text) diff 对齐，同文复用；改过的段给出同卡最相似旧段的译文作参考；frame / gates / BGM 曲名每次整段重译
::   译者把每个 todo 译成 _sync_tr_{k}.json（{path: 译文}），交稿前自检：python tools/i18n_sync.py check <loc> <k>
python tools/i18n_sync.py merge all      :: 校验标记后写回 final_game.json，删除 _sync_* 临时文件
python tools/i18n_apply_glossary.py all
python tools/i18n_check.py all
```

同步完成后请提交一次 git，下次同步才有正确基线。

**整包重译**（新语言或大改）走下面的老管线：简体改完 → 结构对齐 → 专名 → 抽散文 → 回写 → 校验。中间产物（`strings.json` / `prose.json` / `tr_*.json`）可丢，真源永远是各语的 `final_game.json`。

```bat
python tools/i18n_clone.py [de|en|es|fr|ja|ko|hi|zh-TW|all]           :: 从简体拷结构（可译字段仍是中文）
python tools/i18n_apply_glossary.py [de|en|es|fr|ja|ko|hi|zh-TW|all]  :: 词条 name、时间轴列、卡 col、{{eid|显示名}}
python tools/i18n_opencc.py                               :: 仅繁体初稿（优先 s2twp）
python tools/i18n_tw_polish.py                            :: 台湾用词润色
python tools/i18n_strings.py extract [locale]             :: 抽出可译串（JSON Pointer）
python tools/i18n_prose.py [locale]                       :: 去掉 id / look / 路径，得到 prose.json
python tools/i18n_apply_tr.py [locale]                    :: tr_a/b/c.json 写回 prose 再 merge
python tools/i18n_strings.py merge [locale]
python tools/i18n_check.py [locale|all]
```

`i18n_check` 核对：`meta.id`/`version`、卡/词条/闸门 id 集合、`{{eid|名}}` 与 `[[NPCn]]` 数量及 eid 对齐、chip 显示名 = 该语 `entries[id].name`、glossary 专名、blanks 的 slot/kind/answer 与简体一致。

BGM 曲名在 `assets` 下，不走 `i18n_prose`（它跳过 `/assets/`）。改曲名直接改各语 `final_game.json` 的 `title` 字段。

## 6. 宽语排版（de / en / es / fr / hi）

选择器走 `html[lang=…]`（或 `isLatinLocale()` / `isWideLocale()`），不要按标题长度猜。

- **字体**：de/en/es/fr 用 Inter；ja / ko / zh-TW / hi 用系统字体栈 + 简体或 Devanagari 回退，不内联全字库。开篇标题字距 0.03em 只给拉丁四语（印地语不要跟这套 tracking）。
- **词条库**（de/en/es/fr/hi）：单列；姓名换行；地点卡 `.has-bg::before` 高度封顶 110px。
- **情节卡左列**（同上）：形态标签 + 状态章占**第一行**，标题独占**第二行**。中/日/韩/繁仍是单行标题 + 省略号。
- **时间轴人物列头**：允许换行。
- **档案已完成章**：对勾图标，不用「完」印章。
- **故事回顾**：纸纹叠在不滚动的 `.recap-article` 上，滚动交给内层 `.recap-article-scroll`。

## 7. 怎么改 / 怎么扩

- **改一句引擎文案**：改 `frontend/src/i18n/ui/` 九份 JSON 的同一点号键；组件里用 `t('…')`，不要再写死中文。Coach 提示走 `coach.*` 键。
- **改悉达多叙事**：只改简体 `workspace/xidaduo/final_game.json`（或 DEBUG 编辑器），再按 §5 同步语言包。不要在非简体界面点保存。
- **给其它作品加叙事翻译**：仿 `xddPack()` 给该作登记 `i18n/{locale}/final_game.json`，缺的语种继续回退简体即可。
- **加一种玩家语言**：`LOCALES` + UI JSON +（可选）叙事目录 + glossary 新栏 + `i18n_check` 的 `LOCALES` 元组。拉丁文/印地语排版要不要走 §6，看是否会把栏宽撑破。
- **冒烟**：`/?game=xdd&lang=de|en|es|fr|ja|ko|hi|zh-TW`（见 `frontend/tests/smoke.spec.ts`）。热切语言看标题页菜单胶囊。
