# 悉达多 · BGM 设计（音乐圣经）

> 规范见 [doc/14-bgm-pipeline.md](../../../doc/14-bgm-pipeline.md)。真源是 `final_game.json` 的 `assets.bgm`（每条含 `prompt` / `tags` / `note`）；本文只记设计意图，便于后续换曲时保持统一。
> 生成：`python tools/gen_bgm.py xdd --clean`；备选 clip 在 `DEBUG/bgm_alt/`；日志 `DEBUG/bgm_gen_log.json`。

## 1. 全作

- 主题句：一个婆罗门之子，如何在河上听见万音。
- 基调：慢板、旋律为主、器乐、古印度色彩但不做民族音乐展示；始终留有「河」的水声与 tanpura 持续低音作底。
- **河流动机**（全作记忆点）：五音上行再回落的五声音阶乐句，像水面起伏。每一首都以不同乐器 / 速度 / 调式复现或变形它——完整（封面、开篇、结局）、残缺（未满的容器）、变形失真（歌鸟之死）、卡农叠加（万音成唵）。
- 速度分层：卷一 56–100 BPM（干、空、木质）→ 卷二 60–124 BPM（丰满明亮转浑浊）→ 卷三 54–92 BPM（圆融）。封面 66、结局 60。

## 4. 辨识度自检

同关任意两曲在「主奏乐器 / BPM（差 ≥ 15）/ 调性明暗」三项中至少两项不同：
- 卷一：56 / 60 / 72 / 78 / 84 / 92 / 100，主奏各异（大提琴、颂钵、弦乐、竹笛+大提琴、打击乐、竹笛+钢琴、竹笛+kalimba）。
- 卷二：60 / 70 / 88 / 96 / 104 / 112 / 118 / 124；88 与 96 均为 sitar 但明暗相反（小调 vs 摆动）。
- 卷三：54 / 58 / 60 / 62 / 64 / 68 / 76 / 80 / 92——速度接近处靠主奏区分（santoor / 卡农合奏 / 吉他 / 大提琴二重 / sitar 挽歌 / 音乐盒 / 断奏弦乐 / tabla）。

## 5. 换曲流程

DEBUG →「背景音乐」→ 该曲「复制prompt」→ 自行出图站生成 / 或 `python tools/gen_bgm.py xdd --only <id> --force` → 「更换音频」换上（或从 `DEBUG/bgm_alt/<id>.mp3` 选备选）。改 prompt 后记得「保存并生效」。
