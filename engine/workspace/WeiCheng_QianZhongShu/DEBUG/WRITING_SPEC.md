## 1. 输出格式

每片产出**一个 JSON 数组**（情节卡）或**一个 JSON 对象**（entries），写入 `workspace/WeiCheng_QianZhongShu/DEBUG/` 下指定文件。必须合法 JSON（无注释、无尾逗号），UTF-8。

情节卡完整字段样板：

```json
{ "id": "c1_01", "level": 1, "form": "scene", "difficulty": "normal", "len": "M",
  "col": "名场面", "row": 0, "title": "甲板上的点烟",
  "cg": "wc-assets/cg/c1_01.jpg",
  "cgPrompt": "英文一两句镜头描述（见 §5）",
  "cgChars": ["e_fanghongjian", "e_baoxiaojie"],
  "segments": [
    { "kind": "narration", "text": "……[[NPC1]]……{{e_lunchuan|白拉日隆子爵号}}……" },
    { "kind": "dialogue", "slot": "NPC1", "text": "（动作）台词" },
    { "kind": "dialogue", "speakerEntry": "e_suwenwan", "text": "台词" },
    { "kind": "dialogue", "speaker": "孙太太", "text": "台词" },
    { "kind": "monologue", "slot": "NPC1", "text": "第一人称内心" }
  ],
  "blanks": [ { "slot": "NPC1", "kind": "person", "answer": "e_baoxiaojie" },
              { "slot": "地点", "kind": "place", "answer": "e_lunchuan" } ],
  "hints": ["方向（不报名字）", "点破（不报名字）"] }
```

- segments 五形态：`narration`／`dialogue`+`slot`（待猜人物）／`dialogue`+`speakerEntry`（已具名人物）／`dialogue`+`speaker`（纯配角文本名）／`monologue`+`slot`（独白）
- 内联标记：`{{e_x|显示名}}`＝可点词条；`[[NPCn]]`＝匿名人物占位（只写进 narration）
- 地点空数组答案：`"answer": ["e_xikou", "e_tengqiao"]`
- `startUnlocked: true` 仅 c1_01
- col/row 与卡表（design/06）一致；col 取值必须是本关 timelines.cols 之一
