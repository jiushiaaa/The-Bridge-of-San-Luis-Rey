# 《围城》生产纪要（PRODUCTION_NOTES）

> 记录从策划稿到可通关成品之间的一切落地修正。数据生产的权威卡表是 `DEBUG/card_assignments.md`（对 `design/06` 的校正）；写作纪律见 `DEBUG/WRITING_SPEC.md`；取材见 `DEBUG/book_digest.md`。

## 最终规模

- 5 关 / 80 张情节卡（12/16/16/18/18）/ 111 个词条（人物 44、地点 34、物品 18、概念 15）/ 5 道闸门 / 5 关回顾长廊（18 页）/ 过场 5 + 结局 1
- 美术：头像 44 + 词条图 70 + CG 80 + 标题/结局/主题图标/favicon/NPC 剪影，共 194 张（1K / low / jpg，10 线程）
- 难度：简单 24（30%）/ 普通 42（52.5%）/ 困难 14（17.5%）

## 关键落地修正（策划稿 → 成品）

1. **cardSpec.avg = 750**（非默认 700）。本书对话密集，按校验器口径（标点、空白、`[[NPCn]]` 按 7 字全计）内容自然偏长。经测算，avg=750 时 80 卡全部落在档位区间、全卡平均 793 达标。这是策划可设参数，非改引擎。
2. **困难卡在场人物 ≤4**：策划稿中若干群戏困难卡（导师制、汪家晚宴、订婚宴、拜见方家等）在场人物表角色超过 4 个空位上限，已在 card_assignments 中调整难度或精简在场人物。
3. **可收集性（跨卡织入）**：初稿把地名匿名化后，39 个空位答案"全游戏无 chip"。已在"其他卡"里逐一补织（如 西贡→c1_06、礼堂→c1_12、苏家花园→c2_02、韩太太→c4_06），并注意卷内自洽（答案须在本关可收集，如 白拉日隆子爵号 补进 c1_04、藤条长桥 补进 c3_09）。
4. **自指卡修复**：c1_11（演讲）唯一 chip 是"演讲稿"且只在本卡出现，永远无法被搜寻解锁。已让"演讲稿"在 c1_12 也出现，c1_11 经 c1_12 解锁。
5. **0 留白档案页**：引擎中 0 留白页永远无法盖"完"（无核对按钮）。已给阿刘/王美玉/沈太太三个 minor 档案页各补 1 处留白（发钗/侯营长/苏家花园），本关可收集。
6. **档案留白的卷内自洽**：赵辛楣 L2 档案原问"华美新闻社"（L5 地点）改为"曹元朗"；董斜川 L2 的"同情兄"（L3 概念）留白移除（内容并入文本字段）。
7. **一事一卡**：消除 3 处重合（c3_06/c3_07 领路台词改为孙柔嘉内心独白；c4_01 与 c4_02/c4_03 的背景叙述改换视角）。
8. **弧光断线**：通过预埋跨关 chip 消除（高松年→c3_01、方遯翁→c2_07 与 c4_10、曹元朗→c4_15）。
9. **desc 超字**：陆子潇/张太太/张小姐/名片/剧本 5 个 desc 收到 tier 区间内。
