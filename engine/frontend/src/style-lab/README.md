# UI 风格实验室

隔离的视觉实验页，**实验室入口不进入生产构建**，也不读写游戏存档。已选定的纸刊样式已合并进主工程。

## 怎么打开

开发服务器启动后访问：

```text
http://localhost:5174/style-lab.html
```

前端目录执行 `npm run dev`（端口 5174）。不要走 `run.bat` 的生产包——那个只构建 `index.html`。

快捷键 `1`–`6` 切换组合。查询参数会记住当前选择：`?v=v4&s=game&f=phone`。

## 基线（已合并）

纸刊 v6 已迁入生产：`frontend/src/styles.css` token + `frontend/src/theme-editorial.css` 组件规则 + `tab-pill.ts`。游戏页不再挂风格切换条；继续试样式请用本页。

原先生产基线（宣纸 + 皮革棕 + 系统黑体）已替换。

## 候选方案

### Variant v1 · 夜色玻璃档案柜

- 核心隐喻：OLED 纯黑底上的液态玻璃柜
- 视觉关键词：虹彩光斑、毛玻璃、色散描边、金强调
- 适合的游戏情绪：夜读、机密、当代
- 可能的问题：`backdrop-filter` 性能；玻璃上正文对比；与纸质叙事气质冲突

### Variant v2 · 可信进度与层叠卡片

- 核心隐喻：把「补完/归位」做成社会证明与海拔层次
- 视觉关键词：信任蓝、成功绿、大数字、四层阴影
- 适合的游戏情绪：成就感、进度看板
- 可能的问题：偏 SaaS；「读者拼完」是 fixture，不能当真实数据；游戏不像落地页

### Variant v3 · 影院暗场软控件

- 核心隐喻：Cinema Dark 底 + 暗场新拟态凸起
- 视觉关键词：#020203 渐变、靛蓝、双阴影、按压 0.97
- 适合的游戏情绪：沉浸、夜间、影像感
- 可能的问题：新拟态官方不支持暗色；暗双阴影对比弱；与纸质文本阅读冲突

### Variant v4 · 纸粘土

- 核心隐喻：电子墨水纸色 + 可按的粘土凸起
- 视觉关键词：#E4E2DC、双阴影、内凹输入、紫强调仅用于主按钮
- 适合的游戏情绪：手感、安静、实体物件
- 可能的问题：圆角 32px 对桌面三栏偏软；对比度低于纯 E-Ink；信息密度高时阴影发糊

### Variant v5 · 纸刊

- 核心隐喻：报纸杂志栅格，把章节当长文
- 视觉关键词：墨黑细线、衬线、首字下沉、不对称栏
- 适合的游戏情绪：阅读、改编文学、回顾长廊
- 可能的问题：0 圆角在控件密集的情节卡页偏硬；时间轴表格不是杂志版式

### Variant v6 · 纯电子墨水

- 核心隐喻：阅读器：无动画、颗粒、荧光笔选中
- 视觉关键词：#FDFBF7 / #1A1A1A / #FFFF00
- 适合的游戏情绪：慢、专注、接近当前宣纸气质但更克制
- 可能的问题：去掉朱砂/金后状态色全靠形状；黄高亮在档案页可能刺眼

## 开场过场候选（场景「开场过场」）

用「悉达多」三卷的真实文案与插图试排，工具条可切卷、可切「对白样本」检验别的作品的对白段。
文件：`intro/IntroProto.tsx` + `intro/intro-lab.css` + `intro/fixtures.ts`，只在 `main.tsx` 里加载。

四案共同修掉的现状问题：卷名不再在横幅和正文里重复一遍（首段独立成题名幕）；正文不再往下堆叠成一堵墙；
推进按钮不再是通用蓝按钮；插图不再被越涨越大的白面板盖掉。

### Variant A · 独幕字卡

- 核心隐喻：默片幕间字卡
- 版式：无面板，文字直接压在画面上，底部渐变压暗保对比
- 文字策略：一次只留一句，整段淡入上浮；旧句不留
- 交互反馈：底部一排短横做进度，当前段变金变长
- 动效强度：中（26s 缓慢推近 + 0.7s 淡入）
- 可能的问题：长段（110 字）居中排四行，边缘略毛；纯图上文字全靠阴影兜底

### Variant B · 对开书页

- 核心隐喻：精装书摊开，左页插图、右页正文
- 版式：纸色对开 + 书脊压暗 + 插图做贴入式图版
- 文字策略：整页替换（不堆行），首字下沉朱砂色，书口页码用汉字数字
- 交互反馈：翻页横向位移淡入；扉页单独一屏
- 动效强度：低
- 可能的问题：右页下半常年空着；窄屏要退化成上下分栏，插图被压扁

### Variant C · 竖排经卷

- 核心隐喻：经卷自右向左展开
- 版式：右侧铺纸卷（带轴杆），左侧留出画面
- 文字策略：竖排，每段一列，长段自动向左续列；读过的列留在纸上并变淡，旧列从左缘滚出
- 交互反馈：新列自上而下展开（clip-path）
- 动效强度：中
- 可能的问题：段数少时纸面左半大片空白；竖排中文对现代玩家阅读偏慢

### Variant D · 残稿显影

- 核心隐喻：墨迹渗进残稿——与本作「拾起残稿」的核心隐喻同源
- 版式：画面在上，底部一条撕口纸带压在画上
- 文字策略：逐字上墨，点一下立刻显全（不逼人等打字机）
- 交互反馈：笔尖光标 + 底部墨条进度 + 朱砂「残稿」印
- 动效强度：中高
- 可能的问题：逐字显影会拖慢重看；纸带宽度固定，按钮必须跟着纸走
